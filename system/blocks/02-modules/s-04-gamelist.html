S-04 GameList
Games grouped by day, built on exactly the same table as the standings. Federation names open the team page and Box score opens the player-level detail for that game: a header row of fixed-width cells, one el-04 TeamRow per game, and el-13 FederationTag on both sides. Home reads right to the score, away reads left from it, and the losing side is dimmed rather than marked. Conference and stop level only — this module is banned from the landing page (LP-15).

Note
The two earlier attempts both invented a bespoke layout. This one does not: it reuses the table components already proven in R-02 and R-03, so column edges line up with every other table on the site and the row inherits hover, focus and the touch target for free. Score cells are tabular so the digits never shift between rows.
