Note
Stats are GP / PPG / APG / RPG, the configuration already in the brand template. The background is a flat grey placeholder — the key visual, the gradient or a photograph all drop into that layer. The card is locked to 1 : 1.4 and everything inside it is positioned in percentages, so it can be dropped into a four-up roster, a three-up rail or a compact list at any width and hold its proportions — type does not scale with the frame, so a density property steps it down instead: default above 300, compact around 240, dense at 180. The name plate is a solid layer carrying the corner cut, not a gradient fade, so it holds up over any photograph, and it is inset equally on the left, right and bottom. The squad number has been removed. On the Efficiency figure used earlier — that came from the written player-page specification rather than from a published feed and could not be verified as an existing field, so it is out until the data source is confirmed.
