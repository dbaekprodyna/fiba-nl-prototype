Note
Red is used here and nowhere else outside a LIVE marker, which is consistent: this button is only red while a stream is actually running. When the next stream is scheduled or the game has finished the button turns black and the wording changes, so colour never carries a claim the content does not support. The external-link glyph is required because the destination leaves the site.
