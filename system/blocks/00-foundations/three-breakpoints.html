Three breakpoints

Column counts follow the current mainstream convention — four on a handset, eight on a portrait tablet, twelve from laptop width up. Breakpoint boundaries at 600 and 1024 match the Material 3 window-size classes and sit between the Bootstrap sm/md and md/lg steps, so a layout described here translates without re-mapping.

In Figma
Build each breakpoint as its own fixed-width frame — 390, 768 and 1440 — rather than as a fluid layout. Figma has no notion of a fluid grid, so a responsive page still imports as one frame at whatever width it was captured. The three widths become a breakpoint variant property on every module that changes shape.
