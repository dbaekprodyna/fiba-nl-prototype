Branded stroke

The four brand colours drawn as a single angular gradient around the edge of a surface. It is the one place all four appear at once, so it is reserved for a single hero container per page — the season status block on the landing page — and never used on a control or a row.

In Figma
Angular gradient, stroke position Inside, weight 1. Stops at 10 / 53 / 79 / 94 per cent. On an el-00 CutSurface instance this is a second stroke on the same vector, so the gradient follows the 45-degree corner without any extra layer. In HTML the surface carries the gradient as its background and a fill layer covers everything except the outline — which means the parent needs cut-out, a --n value, and a transparent border of the same width.
